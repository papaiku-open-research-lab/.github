# パパ育コミュオープンリサーチラボ 置き場

パパ育コミュは、色々な想いを抱えたパパ達が、時間も場所も選ばずに気軽に集い、それぞれの想いを共有したり、形にしたりしながら、イキイキと自分らしくあるためのプラットフォーム（通称「パパットフォーム」）です。
代表のシカゴリラが育休取得中に家にこもった生活をしていて”うつうつ”とした気持ちになったことをきっかけに、同じ境遇のパパ仲間と気軽に交流できる場所の必要性を感じ2020年6月に設立しました。

パパ育コミュオープンリサーチラボは、家族の生活に役立つ、ちょっとだけ色を添えるリサーチをする場所です。
これまで作ってきたプロダクトをご紹介しています。
